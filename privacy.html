Privacy Policy

Roblox Shorts Uploader · Last updated: November 3, 2026

What this tool is

Roblox Shorts Uploader is an internal tool that uploads videos we create ourselves to our own YouTube channel. It is used only by our team and is not offered to the public.

YouTube API Services

This tool uses the YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data we access

With the permission granted by the channel owner, the tool requests a single permission: youtube.upload. It uses it only to upload videos, together with their title, description and tags, to our own channel. It does not read, collect or store any data about other YouTube users, viewers or channels.

How data is stored

The OAuth access token is stored only locally on the computer of the team member who runs the tool. We do not run a server and do not store any data online. We do not use cookies or analytics, and this website does not collect personal data.

Sharing

We do not sell, share or transfer any data to third parties. Data is only sent to Google/YouTube in order to upload our videos.

Revoking access

Access can be revoked at any time on the Google security settings page. Deleting the locally stored token file also removes the tool's access.
